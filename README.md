# Track Quest from Map

Track quests directly from Starfield's maps with the normal **Activate/Select**
control.

Supported views:

- Surface Map
- Galaxy Map
- System Map

## Requirements

- Steam Starfield 1.16.244
- SFSE 0.2.21
- Address Library for Starfield 1.16.244

## Installation

Install the DLL at:

    Data/SFSE/Plugins/TrackQuestFromMarker.dll

## Building

Generate the Visual Studio solution once:

    xmake project -k vsxmake -m "debug,release,releasedbg"

Then open TrackQuestFromMap.sln and build normally in Visual Studio.
